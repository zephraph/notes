Around this time I got a little distracted. I've started an `_` folder which is just all my misc notes. As I've published more of my notes I find myself trying to figure out where to put things... which is definitely _not_ what I want. So `_` is going to become a new catch-all home for things. I'm also generally considering adopting some symbols as note prefixes in order to conceptually distinguish certain _types_ of notes from their overall location. This is a bit of an effort to start Adopting [[Andy Matuschak]]'s principles of [[Evergreen Notes]]. I really like the [symbol use from mobydiction](https://publish.obsidian.md/mobydiction/notes/_Symbols) wherein a section sign, `§`, represents a structure note, much like an index and a pilcrow sign, `¶`, represents a concept note that defines a concept or idea.
