## Updating meilisearch
- https://docs.meilisearch.com/create/how_to/updating.html#update-to-the-latest-meilisearch-version
	- Initiate a dump
		- `const dumpStatus = await searchClient.createDump()`
	- ssh into gcp instance 
		- `ssh rfd-meilisearch@search.rfd.shared.oxide.computer`
	- Delete the database folder
		- `rm -rf /var/lib/meilisearch/data.ms`
	- Install meilisearch
		- `curl -L https://install.meilisearch.com | sh`
		- Ensure you move the binary to `/usr/bin`
	- Import the dump
		- `meilisearch --import-dump /dumps/<your_dump>.dump`
	- Restart the meilisearch service
		- `sudo systemctl restart meilisearch.service`
