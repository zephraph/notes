The [[📘 Rust Book]] says rustup is a _toolchain multiplexer_. Presumably that means it occupies the same space as [[nvm]], [[rvm]], etc. 

Terms

- Channels -- `stable`, `beta`, or `nightly`
- Toolchain -- A complete installation of the rust compiler and all its related binaries (like `cargo`)
- Target -- The platform
