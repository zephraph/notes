A mechanism built on-top of [[phoenix (elixir)]] that server renders real time UI and tracks the client state in _on the server_. UI updates are sent over [[websockets]] as HTML diffs when state changes. UI interactions are communicated back to the server over [[websockets]].

https://github.com/phoenixframework/phoenix_live_view
