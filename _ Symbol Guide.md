You'll notice many of my notes starting with specific emoji. These are organizational indicators to help hint at content and context of a specific file. 

### Symbolic Overview

| Icon | Purpose                                           |
| ---- | ------------------------------------------------- |
| 💡   | A concept, theory, or definition                  |
| 🗃    | An index of notes                                 |
| 📘   | A non-fiction book                                |
| 📗   | A fictional book                                  |
| 📚   | A collection of references to books or literature |
| 📑   | Detailed notes about a resource I've read         |
| 📍   | A geographical location                           |
| 🗺    | A map detailing multiple location references      |
| 👤   | A reference to a person                           |
| ❔   | An open question                                  |
| ❓   | An answered question                              |
| 💭   | A thought or hypothesis                           |
