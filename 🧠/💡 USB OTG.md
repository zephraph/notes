OTG, short for on-the-go, is a feature that allows a USB device to switch back and forth between the roles of being a Host and being a Device. Normally a phone plugged into a computer would act as a Device. If it had OTG enabled, it would have the ability to switch over to host mode and allow connecting a USB storage device to the phone.
